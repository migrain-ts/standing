# Standing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Before writing any TypeScript, load the `typescript-pro` skill and apply it (see Global Constraints).

**Goal:** Build Standing, a multi-tenant ticketing SaaS (organizer console, buyer storefront, door scanning) with a waiting room, a live dashboard, a "Rush" load simulator, and CSV/XLSX/PDF exports, that runs locally with `docker compose up`.

**Architecture:** npm-workspaces monorepo. `packages/db` (Drizzle schema, migrations, test DB helper, fixtures), `packages/shared` (Zod schemas, branded ids, `Clock`, seat layout), `apps/api` (Hono), `apps/worker` (outbox projector, BullMQ document jobs, hold cleanup), `apps/simulator` (Rush load generator making real HTTP calls), `apps/web` (Next.js + Ant Design + Tailwind v4). Postgres is the only source of truth for seats, orders and tickets; Redis carries the waiting room, job queue, pub/sub and rate limits and may be lost at any time without losing or double-selling a seat. All integration tests run against real PostgreSQL and real Redis.

**Tech Stack:** TypeScript (strict), Node 22+, Hono, Drizzle ORM + drizzle-kit, `pg`, Zod, `@node-rs/argon2`, ioredis, BullMQ, pdfkit, qrcode, exceljs, pg-query-stream, Vitest, Next.js App Router, Ant Design + `@ant-design/nextjs-registry`, Tailwind v4, recharts, Playwright, Docker Compose.

**Spec:** `docs/superpowers/specs/2026-10-18-standing-design.md`

**Execution:** in a git worktree `~/Perso/standing-wt` on branch `build/v1`, created from `main` when execution starts. Nothing is pushed without the user's explicit approval. Commits carry no co-author line.

## Global Constraints

- Everything free, no hosted demo, fictional data only, **simulated payment only**, no real card data anywhere.
- UI and README in English only.
- Package scope is `@standing/*`. Root package name `standing`.
- Versions pinned exactly (`npm i -E`) once installed. Tooling versions copy DoseCare's: typescript 6.0.3, vitest 5.0.5, tsx 4.23.15, eslint 10.12.0, typescript-eslint 8.71.2, prettier 3.9.10, @playwright/test 1.64.1, drizzle-orm 0.45.4, drizzle-kit 0.31.11, pg 8.23.1, hono 4.13.13, @hono/node-server 2.1.5, @hono/zod-validator 0.9.1, zod 4.6.7, @node-rs/argon2 2.2.2, next 16.4.2, react/react-dom 19.3.1, antd 6.6.6, @ant-design/nextjs-registry 1.3.0, @ant-design/cssinjs 2.1.2, @tanstack/react-query 5.104.3, tailwindcss and @tailwindcss/postcss 4.3.3. New libraries (ioredis, bullmq, pdfkit, qrcode, exceljs, pg-query-stream, pg-cursor, recharts) are installed with `npm i -E <name>` and their versions recorded in the commit message.
- **typescript-pro applies to all code.** Concretely: ids are branded types from `@standing/shared` (`SeatId`, `EventId`, `HoldId`, `OrderId`, `TicketId`, `TenantId`, `UserId`, `DocumentId`, ...) and never plain `string` in service signatures; hold, order, document and seat states are discriminated unions or string-literal unions derived from the Drizzle enums, switched exhaustively (`assertNever`); Zod schemas live in `@standing/shared` and types are inferred with `z.infer`; no `any`, no non-null `!` outside tests, no `as` casts except at a validated boundary (database rows via `$type`, parsed JSON via a Zod schema). tRPC is **not** used.
- **Source of truth rule.** Postgres decides every seat, order and ticket. `event_seats.status` changes to `held` only inside `claimSeats` (Task 8) and to `sold` only inside `payHold` (Task 9). Nothing in Redis is ever read to decide whether a seat is free. Redis outage means: waiting room fails open, rate limiting fails open, document jobs are re-enqueued by the sweeper, SSE falls back to snapshots.
- **Time** is read from an injected `Clock`. Application SQL receives `now` as a bound parameter (`${now}::timestamptz`) and never calls `now()`, so tests move time with `FakeClock`. Column defaults (`created_at`) may use `now()`.
- **Money** is integer cents everywhere (`price_cents`, `revenue_cents`). Display formatting happens only in the web app.
- **Tenant isolation:** one `requireTenantRole(min)` middleware is the only authorization point for `/tenants/:tenantId/*`; a non-member gets **404**, a member with too low a role gets **403**. Every handler that loads a child row (event, venue, document) filters on `tenant_id` as well as the row id. A route-coverage test fails when a registered route is neither in the matrix nor explicitly exempt. Row-level security is **not** used (ADR 0005).
- Error body is always `{ error: { code, message } }`. Unknown paths, malformed JSON and validation failures use the same shape.
- Session tokens, scan codes and queue tickets are random or HMAC-signed; session tokens are stored only as SHA-256 hashes.
- Host ports on the developer machine (all bound to 127.0.0.1): Postgres 5441, Redis 6380, API 4100, web 3200 (container port 3000). The simulator listens on 4200 inside the Docker network only. 5432, 5433, 1025, 3000, 3001, 8025 and DoseCare's 5440, 1026, 8026, 4000, 3100 are taken by other projects.
- **Never** run `pkill`, `killall` or `docker stop/rm` against anything that is not this project. Compose is always invoked as `docker compose -p standing ...` from this repository. Redis tests use logical database 15 and `FLUSHDB` on that database only.
- Reusing DoseCare code: `/Users/iloveyou/Perso/dosecare` is a read-only reference (branch `main`, commit `91f438c`). Where a task says "copy", `cp` the file, replace `@dosecare/` with `@standing/` and `dosecare` with `standing`, then apply the listed edits. Never modify the DoseCare repository.
- Docs for libraries are checked with the context7 MCP when an API detail is uncertain (Hono, Drizzle, BullMQ, ioredis, exceljs, pdfkit, Next.js, Ant Design).
- Demo accounts have a known password or a demo-login button and exist only in the local seed (`SEED_DEMO=1`, `DEMO_LOGIN=1`). The README and `docker-compose.yml` say so in a comment.

## Spec deviations decided in this plan

- Orders exist only after a successful payment, so `order_status` is `paid | cancelled` (the spec listed `pending`; the hold is the pending state). Task 2 and the spec are updated.
- Waiting-room admission runs inside the API (idempotent Lua script on every join and status poll) instead of a worker loop, so admission does not depend on a second process. The worker is not needed for the queue to move.
- PDFs are stored in Postgres (`documents.content bytea`), not on a filesystem or object store: nothing to mount, nothing to lose.
- Simulated buyers are real `users` rows flagged `is_simulated`, inserted in bulk by the simulator together with sessions (hashing 5,000 passwords would take minutes). Their HTTP calls go through the same public API as any browser.

## Review Focus

1. **Concurrent holds**: many buyers racing for the same seats get exactly one winner per seat; a multi-seat hold is all-or-nothing and never deadlocks. Pinned in Task 8.
2. **Expiry edges**: an expired hold's seats are reclaimable by someone else immediately; paying after expiry gives 410; paying after another buyer reclaimed a seat gives 410 and sells nothing. Pinned in Tasks 8 and 9.
3. **Redis lost mid-flight**: flushing Redis during a Rush must not oversell or lose a sale; queued buyers re-join; queued documents are re-enqueued. Pinned in Tasks 7, 13 and 16.
4. **Replays**: the same `Idempotency-Key` creates one order; a ticket scanned twice reports the first scan time; a forged or truncated code is rejected without a database write. Pinned in Tasks 9 and 11.
5. **Unbounded inputs**: holds above 8 seats, Rush above 5,000 buyers, venues above 6,000 seats, and report ranges are rejected with 400; exports of 100,000 rows stay within a memory ceiling; the availability endpoint is cached so polling buyers cannot overload Postgres. Pinned in Tasks 5, 6, 8, 14 and 16.

```ts
export type Brand<T, B extends string> = T & { readonly [brand]: B };

export type UserId = Brand<string, 'UserId'>;
export type TenantId = Brand<string, 'TenantId'>;
export type VenueId = Brand<string, 'VenueId'>;
export type SectionId = Brand<string, 'SectionId'>;
export type SeatId = Brand<string, 'SeatId'>;
export type EventId = Brand<string, 'EventId'>;
export type HoldId = Brand<string, 'HoldId'>;
export type OrderId = Brand<string, 'OrderId'>;
export type OrderItemId = Brand<string, 'OrderItemId'>;
export type TicketId = Brand<string, 'TicketId'>;
export type DocumentId = Brand<string, 'DocumentId'>;

export const UUID_RE = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;

export function isUuid(v: unknown): v is string {
  return typeof v === 'string' && UUID_RE.test(v);
}

/** Brands a string that has already been validated (database row, parsed request). */
export function asId<B extends string>(v: string): Brand<string, B> {
  return v as Brand<string, B>;
}

export function assertNever(x: never): never {
  throw new Error(`Unexpected value: ${String(x)}`);
}
```

```ts
export type SectionSpec = { name: string; rows: number; seatsPerRow: number };
export type SeatSpec = {
  sectionIndex: number;
  idx: number;
  rowLabel: string;
  number: number;
  x: number;
  y: number;
};

export const SEAT_PITCH = 20;
export const SECTION_GAP = 60;
export const STAGE_HEIGHT = 80;

export function rowLabelFor(row: number): string {
  let n = row;
  let label = '';
  do {
    label = String.fromCharCode(65 + (n % 26)) + label;
    n = Math.floor(n / 26) - 1;
  } while (n >= 0);
  return label;
}

/** Lays sections out left to right below a stage area; seat idx is stable and consecutive across sections. */
export function generateLayout(sections: readonly SectionSpec[]): SeatSpec[] {
  const seats: SeatSpec[] = [];
  let originX = 0;
  let idx = 0;
  sections.forEach((section, sectionIndex) => {
    for (let r = 0; r < section.rows; r++) {
      for (let c = 0; c < section.seatsPerRow; c++) {
        seats.push({
          sectionIndex,
          idx: idx++,
          rowLabel: rowLabelFor(r),
          number: c + 1,
          x: originX + c * SEAT_PITCH,
          y: STAGE_HEIGHT + r * SEAT_PITCH,
        });
      }
    }
    originX += section.seatsPerRow * SEAT_PITCH + SECTION_GAP;
  });
  return seats;
}
```

```ts
import { sql, type SQL } from 'drizzle-orm';

/** `array[$1::uuid, $2::uuid, ...]`, for use as `= any(${uuidList(ids)})`. drizzle expands JS arrays into tuples, which `any()` cannot take. */
export function uuidList(ids: readonly string[]): SQL {
  if (ids.length === 0) return sql`array[]::uuid[]`;
  return sql`array[${sql.join(ids.map((i) => sql`${i}::uuid`), sql`, `)}]`;
}
```

```ts
import { and, eq } from 'drizzle-orm';
import type { Context, MiddlewareHandler } from 'hono';
import { schema, type TenantRole } from '@standing/db';
import { UUID_RE } from '@standing/shared';
import type { Env } from './app';
import { ApiError } from './errors';

const ORDER: Record<TenantRole, number> = { door: 1, manager: 2, owner: 3 };

export type Resolver = (c: Context<Env>) => string | null;
export const fromParam = (name = 'tenantId'): Resolver => (c) => c.req.param(name) ?? null;

/** The only authorization point for /tenants/:tenantId/*. Non-members get 404, too-low roles 403. */
export function requireTenantRole(min: TenantRole, resolve: Resolver = fromParam()): MiddlewareHandler<Env> {
  return async (c, next) => {
    const resolved = resolve(c);
    if (!resolved || !UUID_RE.test(resolved)) throw new ApiError(404, 'not_found', 'Not found');
    const tenantId = resolved.toLowerCase();
    const [m] = await c
      .get('deps')
```

```ts
export async function addMember(db: Db, o: { tenantId: string; email: string; role: TenantRole }) {
  const [user] = await db.select({ id: schema.users.id }).from(schema.users).where(eq(schema.users.email, o.email));
  if (!user) throw new ApiError(404, 'user_not_found', 'No account with this email');
  const inserted = await db
    .insert(schema.memberships)
    .values({ tenantId: o.tenantId, userId: user.id, role: o.role })
    .onConflictDoNothing()
    .returning({ userId: schema.memberships.userId });
  if (inserted.length === 0) throw new ApiError(409, 'already_member', 'Already a member');
  return { userId: user.id, role: o.role };
}

/** Locks the tenant's membership rows so two concurrent changes cannot both remove the last owner. */
async function withOwnerGuard<T>(db: Db, tenantId: string, userId: string, change: (tx: Parameters<Parameters<Db['transaction']>[0]>[0]) => Promise<T>, leavesOwner: (current: TenantRole) => boolean) {
  return db.transaction(async (tx) => {
    const rows = await tx.execute(sql`select user_id, role from memberships where tenant_id = ${tenantId}::uuid for update`);
    const members = rows.rows as { user_id: string; role: TenantRole }[];
    const target = members.find((m) => m.user_id === userId);
    if (!target) throw new ApiError(404, 'not_found', 'Not found');
    const owners = members.filter((m) => m.role === 'owner').length;
    if (target.role === 'owner' && leavesOwner(target.role) && owners <= 1) {
      throw new ApiError(409, 'last_owner', 'A tenant must keep at least one owner');
    }
    return change(tx);
  });
}

export const changeRole = (db: Db, o: { tenantId: string; userId: string; role: TenantRole }) =>
  withOwnerGuard(
    db, o.tenantId, o.userId,
    async (tx) => {
      await tx.update(schema.memberships).set({ role: o.role })
        .where(and(eq(schema.memberships.tenantId, o.tenantId), eq(schema.memberships.userId, o.userId)));
      return { userId: o.userId, role: o.role };
    },
    () => o.role !== 'owner',
  );

export const removeMember = (db: Db, o: { tenantId: string; userId: string }) =>
  withOwnerGuard(
    db, o.tenantId, o.userId,
    async (tx) => {
      await tx.delete(schema.memberships)
        .where(and(eq(schema.memberships.tenantId, o.tenantId), eq(schema.memberships.userId, o.userId)));
    },
    () => true,
  );
```

```ts
import { and, eq, sql } from 'drizzle-orm';
import { schema, type Db } from '@standing/db';
import { asId, generateLayout, type VenueCreateInput, type VenueId } from '@standing/shared';
import { ApiError } from '../errors';

export type VenueMap = {
  sections: { id: string; name: string; ord: number }[];
  seats: [x: number, y: number, sectionOrd: number, row: string, number: number][];
  seatIds: string[];
  width: number;
  height: number;
};

const CHUNK = 2000;

export async function createVenue(db: Db, o: { tenantId: string } & VenueCreateInput) {
  return db.transaction(async (tx) => {
    const [venue] = await tx.insert(schema.venues).values({ tenantId: o.tenantId, name: o.name }).returning({ id: schema.venues.id, name: schema.venues.name });
    if (!venue) throw new Error('venue insert failed');
    const sectionRows = await tx
      .insert(schema.sections)
      .values(o.sections.map((s, ord) => ({ venueId: venue.id, name: s.name, ord, rows: s.rows, seatsPerRow: s.seatsPerRow })))
      .returning({ id: schema.sections.id, ord: schema.sections.ord });
    const idByOrd = new Map(sectionRows.map((r) => [r.ord, r.id]));
    const layout = generateLayout(o.sections);
    for (let i = 0; i < layout.length; i += CHUNK) {
      await tx.insert(schema.seats).values(
        layout.slice(i, i + CHUNK).map((p) => {
          const sectionId = idByOrd.get(p.sectionIndex);
          if (!sectionId) throw new Error('section missing');
          return { venueId: venue.id, sectionId, idx: p.idx, rowLabel: p.rowLabel, number: p.number, x: p.x, y: p.y };
        }),
      );
    }
    return { id: asId<'VenueId'>(venue.id) as VenueId, name: venue.name, seatCount: layout.length };
  });
}

export async function listVenues(db: Db, tenantId: string) {
  const r = await db.execute(sql`
    select v.id, v.name, count(s.id)::int as seat_count
    from venues v left join seats s on s.venue_id = v.id
    where v.tenant_id = ${tenantId}::uuid group by v.id order by v.name`);
  return r.rows.map((x) => ({ id: String(x.id), name: String(x.name), seatCount: Number(x.seat_count) }));
}

export async function getVenue(db: Db, tenantId: string, venueId: string) {
  const [venue] = await db.select().from(schema.venues).where(and(eq(schema.venues.id, venueId), eq(schema.venues.tenantId, tenantId)));
  if (!venue) throw new ApiError(404, 'not_found', 'Not found');
  const sections = await db.select().from(schema.sections).where(eq(schema.sections.venueId, venue.id)).orderBy(schema.sections.ord);
  return { id: venue.id, name: venue.name, sections };
}

export async function loadVenueMap(db: Db, venueId: string): Promise<VenueMap> {
  const sections = await db
    .select({ id: schema.sections.id, name: schema.sections.name, ord: schema.sections.ord })
    .from(schema.sections).where(eq(schema.sections.venueId, venueId)).orderBy(schema.sections.ord);
  const ordById = new Map(sections.map((s) => [s.id, s.ord]));
  const rows = await db
    .select({ id: schema.seats.id, x: schema.seats.x, y: schema.seats.y, sectionId: schema.seats.sectionId, row: schema.seats.rowLabel, number: schema.seats.number })
    .from(schema.seats).where(eq(schema.seats.venueId, venueId)).orderBy(schema.seats.idx);
  const seats = rows.map((r): VenueMap['seats'][number] => [r.x, r.y, ordById.get(r.sectionId) ?? 0, r.row, r.number]);
  return {
    sections,
    seats,
    seatIds: rows.map((r) => r.id),
    width: rows.reduce((m, r) => Math.max(m, r.x), 0) + 20,
    height: rows.reduce((m, r) => Math.max(m, r.y), 0) + 20,
  };
}
```

`apps/api/src/services/ttl-cache.ts`:
```ts
import type { Clock } from '@standing/shared';

/** Coalesces concurrent reads and reuses a result for `ttlMs` of clock time, so polling clients cannot overload Postgres. */
export class TtlCache<T> {
  private entries = new Map<string, { at: number; value: Promise<T> }>();
  constructor(private load: (key: string) => Promise<T>, private clock: Clock, private ttlMs = 500) {}

  get(key: string): Promise<T> {
    const now = this.clock.now().getTime();
    const hit = this.entries.get(key);
    if (hit && now - hit.at <= this.ttlMs) return hit.value;
    const value = this.load(key);
    this.entries.set(key, { at: now, value });
    value.catch(() => {
      if (this.entries.get(key)?.value === value) this.entries.delete(key);
    });
    return value;
  }
}
```

```ts
import { sql } from 'drizzle-orm';
import type { Db } from '@standing/db';
import type { Clock } from '@standing/shared';

export type Availability = { at: string; held: number[]; sold: number[] };

export function availabilityLoader(db: Db, clock: Clock) {
  return async (eventId: string): Promise<Availability> => {
    const now = clock.now();
    const r = await db.execute(sql`
      select s.idx, es.status
      from event_seats es join seats s on s.id = es.seat_id
      where es.event_id = ${eventId}::uuid
        and (es.status = 'sold' or (es.status = 'held' and es.held_until > ${now}::timestamptz))
      order by s.idx`);
    const held: number[] = [];
    const sold: number[] = [];
    for (const row of r.rows) (row.status === 'sold' ? sold : held).push(Number(row.idx));
    return { at: now.toISOString(), held, sold };
  };
}
```

```ts
import { and, eq, sql } from 'drizzle-orm';
import { schema, type Db, type Tx } from '@standing/db';
import type { Clock } from '@standing/shared';
import { UUID_RE } from '@standing/shared';
import { ApiError } from '../errors';

const notFound = () => new ApiError(404, 'not_found', 'Not found');

export async function loadTenantEvent(db: Db | Tx, tenantId: string, eventId: string) {
  if (!UUID_RE.test(eventId)) throw notFound();
  const [ev] = await db.select().from(schema.events)
    .where(and(eq(schema.events.id, eventId.toLowerCase()), eq(schema.events.tenantId, tenantId)));
  if (!ev) throw notFound();
  return ev;
}

export async function publishEvent(db: Db, clock: Clock, tenantId: string, eventId: string) {
  return db.transaction(async (tx) => {
    if (!UUID_RE.test(eventId)) throw notFound();
    const locked = await tx.execute(sql`
      select id, venue_id, status, starts_at from events
      where id = ${eventId.toLowerCase()}::uuid and tenant_id = ${tenantId}::uuid for update`);
    const ev = locked.rows[0] as { id: string; venue_id: string; status: string; starts_at: Date } | undefined;
    if (!ev) throw notFound();
    if (ev.status !== 'draft') throw new ApiError(409, 'not_draft', 'Only draft events can be published');
    if (new Date(ev.starts_at) <= clock.now()) throw new ApiError(409, 'in_the_past', 'The event date must be in the future');
    const missing = await tx.execute(sql`
      select s.name from sections s
      where s.venue_id = ${ev.venue_id}::uuid
        and not exists (select 1 from price_tiers p where p.event_id = ${ev.id}::uuid and p.section_id = s.id)`);
    if (missing.rows.length > 0) {
      throw new ApiError(409, 'missing_tiers', `No price for: ${missing.rows.map((r) => String(r.name)).join(', ')}`);
    }
    await tx.execute(sql`
      insert into event_seats (event_id, seat_id)
      select ${ev.id}::uuid, id from seats where venue_id = ${ev.venue_id}::uuid`);
    await tx.update(schema.events).set({ status: 'published' }).where(eq(schema.events.id, ev.id));
  });
}
```

```ts
export function createRedis(url: string, log: (line: string) => void = console.error): Redis {
  const seen = new Set<string>();
  const redis = new Redis(url, {
    maxRetriesPerRequest: 1,
    enableOfflineQueue: false,
    retryStrategy: (n) => Math.min(n * 200, 2000),

  redis.on('error', (err: Error) => {
    if (seen.has(err.message)) return;
    seen.add(err.message);
    log(`[redis] ${err.message}`);
  });
  redis.on('ready', () => seen.clear());
  return redis;
}
```

```ts
import { randomBytes } from 'node:crypto';
import type { Redis } from 'ioredis';
import type { Clock } from '@standing/shared';

export type AdmissionState =
  | { state: 'admitted'; expiresAt: number }
  | { state: 'waiting'; position: number; queueLength: number }
  | { state: 'unknown' };
export type Gate = 'open' | 'admitted' | 'denied';

// Atomically drops expired admissions, then moves the head of the queue into the active set until `capacity` is reached.
const ADMIT = `
redis.call('ZREMRANGEBYSCORE', KEYS[2], '-inf', ARGV[1])
local free = tonumber(ARGV[2]) - redis.call('ZCARD', KEYS[2])
if free <= 0 then return 0 end
local ids = redis.call('ZRANGE', KEYS[1], 0, free - 1)
for _, id in ipairs(ids) do
  redis.call('ZREM', KEYS[1], id)
  redis.call('ZADD', KEYS[2], tonumber(ARGV[1]) + tonumber(ARGV[3]), id)
end
return #ids`;

const q = (e: string) => `wr:${e}:q`;
const a = (e: string) => `wr:${e}:a`;
const seq = (e: string) => `wr:${e}:seq`;

export class WaitingRoom {
  private activeTtlMs: number;
  constructor(private redis: Redis, private clock: Clock, opts: { activeTtlMs?: number } = {}) {
    this.activeTtlMs = opts.activeTtlMs ?? 300_000;
  }

  private async admit(eventId: string, capacity: number): Promise<void> {
    await this.redis.eval(ADMIT, 2, q(eventId), a(eventId), this.clock.now().getTime(), capacity, this.activeTtlMs);
  }

  async join(eventId: string, capacity: number) {
    const ticket = randomBytes(12).toString('base64url');
    const n = await this.redis.incr(seq(eventId));
    await this.redis.zadd(q(eventId), 'NX', n, ticket);
    return { ticket, ...(await this.status(eventId, ticket, capacity)) };
  }

  async status(eventId: string, ticket: string, capacity: number): Promise<AdmissionState> {
    await this.admit(eventId, capacity);
    const now = this.clock.now().getTime();
    const expiresAt = await this.redis.zscore(a(eventId), ticket);
    if (expiresAt !== null && Number(expiresAt) > now) return { state: 'admitted', expiresAt: Number(expiresAt) };
    const rank = await this.redis.zrank(q(eventId), ticket);
    if (rank === null) return { state: 'unknown' };
    return { state: 'waiting', position: rank + 1, queueLength: await this.redis.zcard(q(eventId)) };
  }

  async isAdmitted(eventId: string, ticket: string): Promise<boolean> {
    const score = await this.redis.zscore(a(eventId), ticket);
    return score !== null && Number(score) > this.clock.now().getTime();
  }

  async release(eventId: string, ticket: string): Promise<void> {
    await this.redis.zrem(a(eventId), ticket);
    await this.redis.zrem(q(eventId), ticket);
  }

  async stats(eventId: string) {
    return { waiting: await this.redis.zcard(q(eventId)), active: await this.redis.zcard(a(eventId)) };
  }
}

/** Fails open: a missing or broken Redis never blocks a purchase, because Postgres alone prevents overselling. */
export async function checkGate(
  room: WaitingRoom | undefined,
  eventId: string,
  ticket: string | undefined,
  admissionLimit: number,
  log: (line: string) => void = console.error,
): Promise<Gate> {
  if (!room || admissionLimit <= 0) return 'open';
  if (!ticket) return 'denied';
  try {
    return (await room.isAdmitted(eventId, ticket)) ? 'admitted' : 'denied';
  } catch (err) {
    log(`[queue] gate open because Redis failed: ${err instanceof Error ? err.message : String(err)}`);
    return 'open';
  }
}
```

```ts
export function redisRateLimit(o: {
  redis: Redis | undefined;
  clock: Clock;
  prefix: string;
  windowMs: number;
  max: number;
  key: (c: Context) => string;
}): MiddlewareHandler {
  return async (c, next) => {
    if (o.redis) {
      try {
        const window = Math.floor(o.clock.now().getTime() / o.windowMs);
        const k = `rl:${o.prefix}:${o.key(c)}:${window}`;
        const n = await o.redis.incr(k);
        if (n === 1) await o.redis.pexpire(k, o.windowMs * 2);

      } catch (err) {
        if (err instanceof ApiError) throw err; // Redis failure: fail open
      }
    }
    await next();
  };
```

```ts
import { randomUUID } from 'node:crypto';
import { and, eq, sql } from 'drizzle-orm';
import { schema, uuidList, type Tx } from '@standing/db';
import { asId, UUID_RE, type EventId, type HoldId, type SeatId, type SectionId } from '@standing/shared';
import type { Deps } from '../app';
import { ApiError } from '../errors';

export type HoldView = {
  id: HoldId;
  eventId: EventId;
  expiresAt: string;
  totalCents: number;
  seats: { seatId: SeatId; idx: number; sectionId: SectionId; priceCents: number }[];
};

const notFound = () => new ApiError(404, 'not_found', 'Not found');

/**
 * The only place a seat becomes `held`. Rows are locked with SKIP LOCKED so a request never waits behind another
 * buyer; a seat is claimable when available or when its hold has expired. Returns the seat ids actually claimed.
 */
export async function claimSeats(
  tx: Tx,
  o: { eventId: string; holdId: string; seatIds: readonly string[]; now: Date; expiresAt: Date },
): Promise<string[]> {
  const r = await tx.execute(sql`
    with c as (
      select seat_id from event_seats
      where event_id = ${o.eventId}::uuid
        and seat_id = any(${uuidList(o.seatIds)})
        and (status = 'available' or (status = 'held' and held_until < ${o.now}::timestamptz))
      order by seat_id
      for update skip locked
    )
    update event_seats e
    set status = 'held', hold_id = ${o.holdId}::uuid, held_until = ${o.expiresAt}::timestamptz
    from c
    where e.event_id = ${o.eventId}::uuid and e.seat_id = c.seat_id
    returning e.seat_id`);
  return r.rows.map((x) => String(x.seat_id));
}

async function viewOf(tx: Tx, holdId: string): Promise<HoldView> {
  const [hold] = await tx.select().from(schema.holds).where(eq(schema.holds.id, holdId));
  if (!hold) throw notFound();
  const r = await tx.execute(sql`
    select es.seat_id, s.idx, s.section_id, pt.price_cents
    from event_seats es
    join seats s on s.id = es.seat_id
    join price_tiers pt on pt.event_id = es.event_id and pt.section_id = s.section_id
    where es.hold_id = ${holdId}::uuid and es.status = 'held'
    order by s.idx`);
  const seats = r.rows.map((x) => ({
    seatId: asId<'SeatId'>(String(x.seat_id)) as SeatId,
    idx: Number(x.idx),
    sectionId: asId<'SectionId'>(String(x.section_id)) as SectionId,
    priceCents: Number(x.price_cents),
  }));
  return {
    id: asId<'HoldId'>(hold.id) as HoldId,
    eventId: asId<'EventId'>(hold.eventId) as EventId,
    expiresAt: hold.expiresAt.toISOString(),
    totalCents: seats.reduce((n, s) => n + s.priceCents, 0),
    seats,
  };
}

export async function createHold(
  deps: Pick<Deps, 'db' | 'clock' | 'config'>,
  o: { buyerId: string; eventId: string; seatIds: readonly string[] },
): Promise<HoldView> {
  const now = deps.clock.now();
  const expiresAt = new Date(now.getTime() + deps.config.holdTtlSeconds * 1000);
  const seatIds = o.seatIds.map((s) => s.toLowerCase());
  return deps.db.transaction(async (tx) => {
    const [event] = await tx.select({ status: schema.events.status }).from(schema.events).where(eq(schema.events.id, o.eventId));
    if (!event || event.status !== 'published') throw notFound();

    // Replace the buyer's previous active hold for this event. If the new claim fails the whole transaction rolls back.
    await tx.execute(sql`
      update event_seats set status = 'available', hold_id = null, held_until = null
      where event_id = ${o.eventId}::uuid and status = 'held'
        and hold_id in (select id from holds where buyer_id = ${o.buyerId}::uuid and event_id = ${o.eventId}::uuid and status = 'active')`);
    await tx.execute(sql`
      update holds set status = 'cancelled'
      where buyer_id = ${o.buyerId}::uuid and event_id = ${o.eventId}::uuid and status = 'active'`);

    const holdId = randomUUID();
    await tx.insert(schema.holds).values({ id: holdId, buyerId: o.buyerId, eventId: o.eventId, seatCount: seatIds.length, expiresAt });
    const claimed = new Set(await claimSeats(tx, { eventId: o.eventId, holdId, seatIds, now, expiresAt }));
    if (claimed.size !== seatIds.length) {
      const known = await tx.execute(sql`
        select seat_id from event_seats where event_id = ${o.eventId}::uuid and seat_id = any(${uuidList(seatIds)})`);
      const knownIds = new Set(known.rows.map((x) => String(x.seat_id)));
      if (seatIds.some((s) => !knownIds.has(s))) throw new ApiError(400, 'unknown_seat', 'Some seats are not part of this event');
      throw new ApiError(409, 'seats_unavailable', 'Some seats are no longer available', {
        taken: seatIds.filter((s) => !claimed.has(s)),
      });
    }
    return viewOf(tx, holdId);
  });
}

export async function getHold(deps: Pick<Deps, 'db'>, o: { buyerId: string; holdId: string }): Promise<HoldView> {
  if (!UUID_RE.test(o.holdId)) throw notFound();
  return deps.db.transaction(async (tx) => {
    const [hold] = await tx.select({ id: schema.holds.id }).from(schema.holds)
      .where(and(eq(schema.holds.id, o.holdId.toLowerCase()), eq(schema.holds.buyerId, o.buyerId), eq(schema.holds.status, 'active')));
    if (!hold) throw notFound();
    return viewOf(tx, hold.id);
  });

export async function cancelHold(deps: Pick<Deps, 'db'>, o: { buyerId: string; holdId: string }): Promise<void> {
```

```ts
import { and, eq, sql } from 'drizzle-orm';
import { schema, type Db, type Tx } from '@standing/db';
import { asId, UUID_RE, type DocumentId, type EventId, type OrderId, type SeatId, type TicketId } from '@standing/shared';
import type { Deps } from '../app';
import { ApiError } from '../errors';
import { signTicket } from '@standing/core';

const sleep = (ms: number) => new Promise<void>((r) => setTimeout(r, ms));
const notFound = () => new ApiError(404, 'not_found', 'Not found');
const expired = () => new ApiError(410, 'hold_expired', 'This reservation has expired');

export type OrderView = {
  id: OrderId;
  eventId: EventId;
  totalCents: number;
  createdAt: string;
  documentId: DocumentId | null;
  tickets: { id: TicketId; seatId: SeatId; rowLabel: string; number: number; sectionName: string; priceCents: number; code: string }[];
};
export type PayResult = { kind: 'paid'; replayed: boolean; order: OrderView } | { kind: 'declined' };

export async function loadOrderView(db: Db | Tx, secret: string, orderId: string): Promise<OrderView> {
  const [order] = await db.select().from(schema.orders).where(eq(schema.orders.id, orderId));
  if (!order) throw notFound();
  const rows = await db.execute(sql`
    select t.id as ticket_id, t.seat_id, s.row_label, s.number, sec.name as section_name, oi.price_cents
    from tickets t
    join order_items oi on oi.id = t.order_item_id
    join seats s on s.id = t.seat_id
    join sections sec on sec.id = s.section_id
    where t.order_id = ${orderId}::uuid order by s.idx`);
  const [doc] = await db.select({ id: schema.documents.id }).from(schema.documents)
    .where(and(eq(schema.documents.orderId, orderId), eq(schema.documents.kind, 'ticket_pdf')));
  return {
    id: asId<'OrderId'>(order.id) as OrderId,
    eventId: asId<'EventId'>(order.eventId) as EventId,
    totalCents: order.totalCents,
    createdAt: order.createdAt.toISOString(),
    documentId: doc ? (asId<'DocumentId'>(doc.id) as DocumentId) : null,
    tickets: rows.rows.map((r) => {
      const id = asId<'TicketId'>(String(r.ticket_id)) as TicketId;
      return {
        id,
        seatId: asId<'SeatId'>(String(r.seat_id)) as SeatId,
        rowLabel: String(r.row_label),
        number: Number(r.number),
        sectionName: String(r.section_name),
        priceCents: Number(r.price_cents),
        code: signTicket(secret, id),
      };
    }),
  };
}

export async function payHold(
  deps: Pick<Deps, 'db' | 'clock' | 'config' | 'random'>,
  o: { holdId: string; buyerId: string; idempotencyKey: string },
): Promise<PayResult> {
  if (!UUID_RE.test(o.holdId)) throw notFound();
  const holdId = o.holdId.toLowerCase();
  // Simulated gateway: latency and the random decision happen before the transaction so no row lock is held while "calling the bank".
  if (deps.config.paymentLatencyMs > 0) await sleep(deps.config.paymentLatencyMs);
  const willFail = (deps.random ?? Math.random)() < deps.config.paymentFailureRate;

  return deps.db.transaction(async (tx) => {
    const now = deps.clock.now();
    const locked = await tx.execute(sql`
      select h.id, h.event_id, h.seat_count, h.status, h.expires_at, e.tenant_id
      from holds h join events e on e.id = h.event_id
      where h.id = ${holdId}::uuid and h.buyer_id = ${o.buyerId}::uuid for update of h`);
    const hold = locked.rows[0] as { id: string; event_id: string; seat_count: number; status: string; expires_at: Date; tenant_id: string } | undefined;
    if (!hold) throw notFound();

    const [prior] = await tx.select().from(schema.payments)
      .where(and(eq(schema.payments.holdId, holdId), eq(schema.payments.idempotencyKey, o.idempotencyKey)));
    if (prior) {
      if (prior.status === 'failed' || !prior.orderId) return { kind: 'declined' };
      return { kind: 'paid', replayed: true, order: await loadOrderView(tx, deps.config.ticketSecret, prior.orderId) };
    }
    if (hold.status === 'paid') throw new ApiError(409, 'already_paid', 'This reservation is already paid');
    if (hold.status !== 'active' || new Date(hold.expires_at) <= now) throw expired();

    const seats = await tx.execute(sql`
      select es.seat_id from event_seats es
      where es.hold_id = ${holdId}::uuid and es.status = 'held' and es.held_until > ${now}::timestamptz
      for update of es`);
    if (seats.rows.length !== hold.seat_count) throw expired();

    if (willFail) {
      await tx.insert(schema.payments).values({ holdId, idempotencyKey: o.idempotencyKey, status: 'failed' });
      return { kind: 'declined' };
    }
    const totalRow = await tx.execute(sql`
      select coalesce(sum(pt.price_cents), 0)::int as total
      from event_seats es
      join seats s on s.id = es.seat_id
      join price_tiers pt on pt.event_id = es.event_id and pt.section_id = s.section_id
      where es.hold_id = ${holdId}::uuid and es.status = 'held'`);
    const total = Number(totalRow.rows[0]?.total ?? 0);
    const [order] = await tx
      .insert(schema.orders)
      .values({ buyerId: o.buyerId, eventId: hold.event_id, tenantId: hold.tenant_id, holdId, totalCents: total, createdAt: now })
      .returning({ id: schema.orders.id });
    if (!order) throw new Error('order insert failed');
    await tx.execute(sql`
      insert into order_items (order_id, event_id, seat_id, section_id, price_cents)
      select ${order.id}::uuid, es.event_id, es.seat_id, s.section_id, pt.price_cents
      from event_seats es
      join seats s on s.id = es.seat_id
      join price_tiers pt on pt.event_id = es.event_id and pt.section_id = s.section_id
      where es.hold_id = ${holdId}::uuid and es.status = 'held'`);
    await tx.execute(sql`
      insert into tickets (order_item_id, order_id, event_id, seat_id)
      select id, order_id, event_id, seat_id from order_items where order_id = ${order.id}::uuid`);
    const sold = await tx.execute(sql`
      update event_seats set status = 'sold', order_id = ${order.id}::uuid, held_until = null
      where hold_id = ${holdId}::uuid and status = 'held'
      returning seat_id`);
    if (sold.rows.length !== hold.seat_count) throw expired(); // throwing rolls the whole transaction back
    await tx.update(schema.holds).set({ status: 'paid' }).where(eq(schema.holds.id, holdId));
    await tx.insert(schema.payments).values({ holdId, idempotencyKey: o.idempotencyKey, status: 'succeeded', orderId: order.id });
    const items = await tx.execute(sql`
      select oi.seat_id, s.idx, oi.section_id, oi.price_cents
      from order_items oi join seats s on s.id = oi.seat_id
      where oi.order_id = ${order.id}::uuid order by s.idx`);
    await tx.insert(schema.outbox).values({
      kind: 'ticket.sold',
      tenantId: hold.tenant_id,
      eventId: hold.event_id,
      dedupeKey: `ticket.sold:${order.id}`,
      createdAt: now,
      payload: {
        orderId: order.id,
        at: now.toISOString(),
        revenueCents: total,
        seats: items.rows.map((r) => ({ seatId: String(r.seat_id), idx: Number(r.idx), sectionId: String(r.section_id), priceCents: Number(r.price_cents) })),
      },
    });
    await tx.insert(schema.documents).values({
      tenantId: hold.tenant_id, kind: 'ticket_pdf', orderId: order.id, eventId: hold.event_id, requestedBy: o.buyerId,
    });
    return { kind: 'paid', replayed: false, order: await loadOrderView(tx, deps.config.ticketSecret, order.id) };
  });
}
```

- Contract: a batch is claimed with `FOR UPDATE SKIP LOCKED` ordered by `id`; rollup upserts and the `processed_at` update happen in the same transaction, so each outbox row affects the rollups exactly once even with several workers; deltas are published **after** commit and a publish failure never undoes a projection. Rows of an unknown kind or with an invalid payload are marked processed and counted in `skipped` (a poison row must not block the queue).

```ts
import { inArray, sql } from 'drizzle-orm';
import { schema, type Db } from '@standing/db';
import { ticketScannedPayload, ticketSoldPayload, type EventDelta } from '@standing/core';
import type { Clock } from '@standing/shared';

export type Publisher = (delta: EventDelta) => Promise<void>;
type OutboxRow = { id: number; kind: string; tenant_id: string; event_id: string; payload: unknown };

const minuteOf = (iso: string) => new Date(Math.floor(Date.parse(iso) / 60_000) * 60_000);

export async function projectOutbox(
  db: Db,
  o: { clock: Clock; batchSize?: number; publish?: Publisher; log?: (line: string) => void },
): Promise<{ processed: number; skipped: number }> {
  const log = o.log ?? console.error;
  const result = await db.transaction(async (tx) => {
    const claimed = await tx.execute(sql`
      select id, kind, tenant_id, event_id, payload from outbox
      where processed_at is null order by id limit ${o.batchSize ?? 200} for update skip locked`);
    const rows = claimed.rows as OutboxRow[];
    const minute = new Map<string, { eventId: string; bucket: Date; tickets: number; revenue: number }>();
    const section = new Map<string, { eventId: string; sectionId: string; tickets: number; revenue: number }>();
    const deltas = new Map<string, EventDelta>();
    const at = o.clock.now().toISOString();
    let skipped = 0;
    for (const row of rows) {
      const delta = deltas.get(row.event_id) ?? { eventId: row.event_id, tenantId: row.tenant_id, tickets: 0, revenueCents: 0, seats: [], scanned: 0, at };
      deltas.set(row.event_id, delta);
      if (row.kind === 'ticket.sold') {
        const p = ticketSoldPayload.safeParse(row.payload);
        if (!p.success) { skipped++; continue; }
        const bucket = minuteOf(p.data.at);
        const mk = `${row.event_id}|${bucket.toISOString()}`;
        const m = minute.get(mk) ?? { eventId: row.event_id, bucket, tickets: 0, revenue: 0 };
        m.tickets += p.data.seats.length;
        m.revenue += p.data.revenueCents;
        minute.set(mk, m);
        for (const seat of p.data.seats) {
          const sk = `${row.event_id}|${seat.sectionId}`;
          const s = section.get(sk) ?? { eventId: row.event_id, sectionId: seat.sectionId, tickets: 0, revenue: 0 };
          s.tickets += 1;
          s.revenue += seat.priceCents;
          section.set(sk, s);
          delta.seats.push({ idx: seat.idx, sectionId: seat.sectionId });
        }
        delta.tickets += p.data.seats.length;
        delta.revenueCents += p.data.revenueCents;
      } else if (row.kind === 'ticket.scanned') {
        if (!ticketScannedPayload.safeParse(row.payload).success) { skipped++; continue; }
        delta.scanned += 1;
      } else {
        skipped++;
      }
    }
    for (const m of minute.values()) {
      await tx.insert(schema.salesByMinute).values({ eventId: m.eventId, bucket: m.bucket, tickets: m.tickets, revenueCents: m.revenue })
        .onConflictDoUpdate({
          target: [schema.salesByMinute.eventId, schema.salesByMinute.bucket],
          set: { tickets: sql`${schema.salesByMinute.tickets} + excluded.tickets`, revenueCents: sql`${schema.salesByMinute.revenueCents} + excluded.revenue_cents` },
        });
    }
    for (const s of section.values()) {
      await tx.insert(schema.salesBySection).values({ eventId: s.eventId, sectionId: s.sectionId, tickets: s.tickets, revenueCents: s.revenue })
        .onConflictDoUpdate({
          target: [schema.salesBySection.eventId, schema.salesBySection.sectionId],
          set: { tickets: sql`${schema.salesBySection.tickets} + excluded.tickets`, revenueCents: sql`${schema.salesBySection.revenueCents} + excluded.revenue_cents` },
        });
    }
    if (rows.length > 0) {
      await tx.update(schema.outbox).set({ processedAt: o.clock.now() }).where(inArray(schema.outbox.id, rows.map((r) => r.id)));
    }
    return { processed: rows.length, skipped, deltas: [...deltas.values()].filter((d) => d.tickets > 0 || d.scanned > 0) };
  });
  // After commit: best effort. Clients resynchronise from a snapshot, so a lost delta is a delay, never a wrong number.
  if (o.publish) {
    for (const d of result.deltas) {
      try {
        await o.publish(d);
      } catch (err) {
        log(`[projector] publish failed: ${err instanceof Error ? err.message : String(err)}`);
      }
    }
  }
  return { processed: result.processed, skipped: result.skipped };
}
```

```ts
/** Housekeeping only: correctness never depends on it, because claimSeats reclaims expired holds on its own. */
export async function releaseExpiredHolds(db: Db, clock: Clock): Promise<{ seats: number; holds: number }> {
  const now = clock.now();

    return { seats: seats.rows.length, holds: holds.rows.length };
  });
}
```

```ts
import type { Db } from '@standing/db';
import type { Clock } from '@standing/shared';
import { releaseExpiredHolds } from './cleanup';
import { refreshDailySales } from './matview';
import { projectOutbox, type Publisher } from './projector';

export type CycleState = { lastRefreshAt: number };

export async function runCycle(
  db: Db,
  deps: { clock: Clock; publish?: Publisher; state: CycleState; refreshEveryMs?: number; batchSize?: number },
) {
  const batchSize = deps.batchSize ?? 200;
  let projected = 0;
  for (let i = 0; i < 20; i++) {
    const r = await projectOutbox(db, { clock: deps.clock, batchSize, ...(deps.publish ? { publish: deps.publish } : {}) });
    projected += r.processed;
    if (r.processed < batchSize) break;
  }
  const released = await releaseExpiredHolds(db, deps.clock);
  const now = deps.clock.now().getTime();
  if (now - deps.state.lastRefreshAt >= (deps.refreshEveryMs ?? 60_000)) {
    await refreshDailySales(db);
    deps.state.lastRefreshAt = now;
  }
  return { projected, released };
}
```

```ts
import { sql } from 'drizzle-orm';
import { verifyTicket } from '@standing/core';
import { asId, type EventId, type TicketId } from '@standing/shared';
import type { Deps } from '../app';
import { ApiError } from '../errors';

export type TicketInfo = { id: TicketId; eventId: EventId; eventName: string; sectionName: string; rowLabel: string; number: number };
export type ScanResult =
  | { result: 'admitted'; ticket: TicketInfo; scannedAt: string }
  | { result: 'already_scanned'; ticket: TicketInfo; firstScannedAt: string }
  | { result: 'wrong_event'; ticket: TicketInfo };

export async function scanTicket(
  deps: Pick<Deps, 'db' | 'clock' | 'config'>,
  o: { userId: string; code: string; eventId?: string | undefined },
): Promise<ScanResult> {
  const ticketId = verifyTicket(deps.config.ticketSecret, o.code);
  if (!ticketId) throw new ApiError(400, 'invalid_code', 'This code is not a valid ticket');
  return deps.db.transaction(async (tx) => {
    const found = await tx.execute(sql`
      select t.id, t.event_id, t.scanned_at, e.name as event_name, e.tenant_id,
             sec.name as section_name, s.row_label, s.number
      from tickets t
      join events e on e.id = t.event_id
      join seats s on s.id = t.seat_id
      join sections sec on sec.id = s.section_id
      where t.id = ${ticketId}::uuid
      for update of t`);
    const row = found.rows[0];
    if (!row) throw new ApiError(404, 'not_found', 'Not found');
    const member = await tx.execute(sql`
      select 1 from memberships where tenant_id = ${String(row.tenant_id)}::uuid and user_id = ${o.userId}::uuid`);
    if (member.rows.length === 0) throw new ApiError(404, 'not_found', 'Not found');
    const ticket: TicketInfo = {
      id: ticketId,
      eventId: asId<'EventId'>(String(row.event_id)) as EventId,
      eventName: String(row.event_name),
      sectionName: String(row.section_name),
      rowLabel: String(row.row_label),
      number: Number(row.number),
    };
    if (o.eventId && o.eventId.toLowerCase() !== String(row.event_id)) return { result: 'wrong_event', ticket };
    if (row.scanned_at) return { result: 'already_scanned', ticket, firstScannedAt: new Date(row.scanned_at as string).toISOString() };
    const now = deps.clock.now();
    await tx.execute(sql`update tickets set scanned_at = ${now}::timestamptz, scanned_by = ${o.userId}::uuid where id = ${ticketId}::uuid`);
    await tx.execute(sql`
      insert into outbox (kind, tenant_id, event_id, payload, dedupe_key, created_at)
      values ('ticket.scanned', ${String(row.tenant_id)}::uuid, ${String(row.event_id)}::uuid,
              ${JSON.stringify({ ticketId, at: now.toISOString() })}::jsonb, ${`ticket.scanned:${ticketId}`}, ${now}::timestamptz)`);
    return { result: 'admitted', ticket, scannedAt: now.toISOString() };
  });
}
```

```ts
export async function oversold(db: Db, eventId: string): Promise<number> {
  const r = await db.execute(sql`
    select
      (select count(*) from tickets where event_id = ${eventId}::uuid)::int as tickets,
      (select count(*) from event_seats where event_id = ${eventId}::uuid and status = 'sold')::int as sold,
      (select count(*) from (select seat_id from order_items where event_id = ${eventId}::uuid group by seat_id having count(*) > 1) d)::int as dup`);
  const row = r.rows[0];
  return Math.abs(Number(row?.tickets) - Number(row?.sold)) + Number(row?.dup);
}
```

```ts
import { createHash, randomBytes } from 'node:crypto';
import { schema, type Db } from '@standing/db';

const CHUNK = 1000;
export async function createSimulatedBuyers(db: Db, runId: string, n: number, now: Date = new Date()): Promise<string[]> {
  const tokens: string[] = [];
  for (let start = 0; start < n; start += CHUNK) {
    const size = Math.min(CHUNK, n - start);
    const users = await db
      .insert(schema.users)
      .values(Array.from({ length: size }, (_, i) => ({
        email: `sim-${runId}-${start + i}@sim.standing.local`, passwordHash: '!', name: `Sim Buyer ${start + i + 1}`, isSimulated: true,
      })))
      .returning({ id: schema.users.id });
    const chunkTokens = users.map(() => randomBytes(24).toString('base64url'));
    await db.insert(schema.sessions).values(
      users.map((u, i) => ({
        userId: u.id,
        tokenHash: createHash('sha256').update(chunkTokens[i]!).digest('hex'),
        expiresAt: new Date(now.getTime() + 24 * 3600_000),
      })),
    );
    tokens.push(...chunkTokens);
  }
  return tokens;
}
```

```ts
export class ApiClientError extends Error {
  constructor(public status: number, public code: string, message: string, public details?: unknown) {
    super(message);
  }
}

export async function api<T>(path: string, init: RequestInit & { json?: unknown } = {}): Promise<T> {
  const { json, headers, ...rest } = init;
  const res = await fetch(`/api${path}`, {
    ...rest,
    credentials: 'same-origin',
    headers: { ...(json !== undefined ? { 'content-type': 'application/json' } : {}), ...headers },
    body: json !== undefined ? JSON.stringify(json) : rest.body,
  });
  if (res.status === 204) return undefined as T;
  const text = await res.text();
  let data: unknown;
  try {
    data = text ? JSON.parse(text) : undefined;
  } catch {
    data = undefined;
  }
  if (!res.ok) {
    const e = (data as { error?: { code?: string; message?: string; details?: unknown } } | undefined)?.error;
    throw new ApiClientError(res.status, e?.code ?? 'http_error', e?.message ?? res.statusText, e?.details);
  }
  return data as T;
}
```
